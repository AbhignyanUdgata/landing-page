01

Anon Boards

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Supabase (Postgres + Edge Functions)

  • Built and deployed an anonymous message board web app where users post and reply without creating an account, with automatic anonymous ID assignment per visitor.
  • Implemented topic-based boards with New/Hot/Top sorting, threaded replies, and a likes system driving the Hot feed ranking across multiple boards.
  • Designed an optional account system via Supabase Auth, letting users save a username and track post/reply history across sessions.
  • Built and deployed 10+ Supabase Edge Functions (Hono) as the backend API layer, backed by a Postgres + key-value store, and deployed live on Vercel.
  • Iterated on an earlier prototype into a full React/TypeScript rebuild across 20+ commits, improving structure and UI with shadcn/ui components.

02

Crate

HTML · JavaScript · Google OAuth

  • Built a client-side web app that converts a Spotify playlist export (CSV) into clickable YouTube search links for every track, removing the need to manually search each song.
  • Integrated with Exportify, a third-party Spotify CSV export tool, to create an end-to-end playlist-to-YouTube workflow.
  • Added automatic CSV column detection for song title/artist fields, with manual override dropdowns for edge cases.
  • Implemented convenience features: bulk-opening the first 10 tracks as tabs, copy-all-links, and a downloadable .txt export.
  • Added optional Google sign-in so users can save and revisit playlists, while keeping core functionality fully client-side and account-free by default.
  • Deployed the project live on Vercel with zero backend dependency for the core conversion flow.

03

Orca Swarm

Python · LangGraph · LangChain · Streamlit · Multi-agent LLM orchestration

  • Built a decentralized multi-agent reasoning system on LangGraph with five specialized roles — Scout, Analyst, Verifier, Challenger, and Synthesizer — as a deliberate contrast to a single monolithic chain of thought.
  • Implemented an append-only shared signal stream (PodState.signals) merged through a LangGraph reducer, so every agent reads the full, ever-growing state instead of receiving point-to-point messages.
  • Designed content-driven routing (decide_next) that selects the next agent from what is currently true in the shared stream, removing any central orchestrator that assigns subtasks.
  • Added a Verifier and an adversarial Challenger plus a convergence gate (confidence threshold and no unresolved strong challenge) that decides when the pod has settled.
  • Wired four swappable LLM providers (Anthropic, OpenAI, Google Gemini, and a local LM Studio server) with per-role model and temperature overrides from a single config module.
  • Shipped a Streamlit web front-end and a CLI over the identical compiled graph, with a 12-test suite that exercises the hypothesis-revision loop using a fake LLM and no network access.
